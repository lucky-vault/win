# Lucky Vault — Modern Refresh
Responsive midnight navy, electric cyan and violet redesign.

Upload the CONTENTS of this folder to the root of the GitHub repository. Keep `css`, `js` and `assets` folders in place. Netlify publish directory: `.`; build command: blank.

This is a visual preview only. Account forms are non-functional. No real-money wagering, deposits, withdrawals or prizes are enabled. Do not launch regulated features until licensing, legal review, age/identity checks, responsible-play safeguards and security requirements are satisfied.
